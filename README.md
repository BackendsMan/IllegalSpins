# Illegal Spins

Weapon spin wheel for the Illegal Civ tiers (Tier 1, 1.5, 2). Pick a tier, pick how many spins, spin.

Fair draw: every gun has equal odds overall. A gun that just dropped is less likely to drop again right away, so repeats can happen but streaks (like 4 of the same gun) are very rare.

```
npm install
npm run dev      # local
npm run check    # draw fairness self-check
npm run build
```

Deploys to GitHub Pages on push to main (Settings → Pages → Source: GitHub Actions).
