# Illegal Spins

Weapon spin wheel for the Illegal Civ tiers (Tier 1, 1.5, 2). Pick a tier, pick how many spins, spin.

Fair draw: every gun has equal odds. Repeats and pairs happen at normal random rates, but the same gun never shows up more than 3 times in any 20 spins.

```
npm install
npm run dev      # local
npm run check    # draw fairness self-check
npm run build
```

Deploys to GitHub Pages on push to main (Settings → Pages → Source: GitHub Actions).
